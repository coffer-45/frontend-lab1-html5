## Запуск

Відкрийте `index.html` у браузері. Сторінка статична й не потребує встановлення пакетів або збірки.

## Файли

- `index.html` — розмітка сторінки;
- `style.css` — оформлення та адаптивність;
- `mukachevo-center.jpg` — фотографія міста;
- `lab1.typ` — вихідний код звіту;
- `lab1.pdf` — звіт;
- `page-screenshot.png` — скриншот сторінки для звіту.
- `hero-screenshot.png` — скриншот першого екрана у звіті.
